# حكايتنا — عيسى وآمنة

رحلة تفاعلية مرسومة من أول صدفة بالقصر الروماني (16/1) لحد موعد الزفاف المنتظر (30/10/2026).
مبنية كنسخة مستقلة من محرّك **مشروع إيلاف** (`adolsatar-sketch/elo-world`): نفس نظام المشاهد والكاميرا وطبقات الـparallax والحوار وتحريك الشخصيات بأجزاء والألغاز والصوت وإطار الألعاب — بمحتوى عيسى وآمنة وحدهم. ما بيها أي اسم أو صورة أو نص من إيلاف.

## التشغيل

موقع ثابت بدون build. أي سيرفر ملفات يكفي:

```bash
npx http-server -p 8765 .
# بعدين افتحوا http://localhost:8765
```

(فتح `index.html` مباشرة من الملفات ممكن ما يشتغل لأن المتصفح يمنع بعض الطلبات المحلية.)

## الأقسام

| القسم | الملف | شنو بيه |
|---|---|---|
| الرئيسية | `js/core.js` | العد التنازلي لموعد الزفاف، التقدّم، المداخل |
| الحكاية | `story/hk-engine.js`, `story/hk-chapters.js` | طريق المحطات + 12 محطة (منها «يوم خطوبتهم» 13/2/2026 مستقلة، و«يوم الزفاف — الموعد المنتظر» 30/10/2026 كموعد مستقبلي) + نهاية عدول |
| الألعاب | `games/games.js` | 5 ألعاب: تتذكرها؟، جمّع الذكرى، لقطة من القصر (الثلاث الأساسية)، شنو تتذكرون؟، جهزوا البيت |
| رسائلنا | `js/letters.js`, `data/letters.js` | الرسائل الحقيقية منقولة من اللقطات كما هي |
| حائط ذكرياتنا | `js/wall.js` | جدار صور + إضافة/تعديل/حذف ذكريات |

النهاية (عدول) ما تنفتح إلا بعد إكمال كل المحطات والألعاب الأساسية الثلاث. من الإعدادات، «إتاحة الحكاية كاملة» تفتح المحطات بأي ترتيب وتلغي شرط الألعاب — بس المحطات لازم تخلص.

## الشخصيات

- `assets/characters/isa.webp`, `amna.webp`, `pair.webp`: مقصوصة من المرجع المعتمد `isa_amna_identity_character_reference.png`، وكل وحدة مقسّمة لطبقات (`<who>-<part>.webp`) تتحرك حول مفاصلها (`story/hk-rig.js`). ما انرسم أي وجه جديد.
- `assets/characters/adool.webp`: ملف عدول الرسمي من مشروع إيلاف.
- الأدوات اللي سوّت الطبقات: `tools/build_rig.py` (تحتاج الصور المقصوصة بدقة كاملة).

## الصور

- الصور بالموقع نسخ WebP مصغّرة (480 و1280 بكسل، بدون بيانات EXIF/الموقع). الملفات الأصلية ما انعدلت وما انرفعت.
- `ASSET_INDEX.md` يربط كل صورة أصلية بمحتواها والمحطة والتاريخ ودرجة الثقة؛ اللي ما نعرفه مكتوب «غير معروف».
- إضافة صورة أصلية جديدة للمشروع: أضيفوا سطر بـ `tools/photos_manifest.py` وشغّلوا:
  ```bash
  python tools/build_photos.py <مجلد الصور الأصلية> .
  ```

## وين تنحفظ الأشياء (مهم)

كل شي **محلي بهذا المتصفح على هذا الجهاز**:

- تقدّم الحكاية والألعاب والإعدادات: `localStorage` (مفاتيح تبدي بـ `hk_`).
- ذكريات الحائط المضافة وصورها: IndexedDB (`hk-wall`) — الصورة تتصغّر بالجهاز لحد 1600 بكسل قبل الحفظ.
- ما في تزامن تلقائي بين الأجهزة. للنقل: **الإعدادات ← تصدير نسخة احتياطية**، وبالجهاز الثاني **استيراد نسخة**.
- مسح بيانات المتصفح أو التصفح الخاص يمسح الذكريات المضافة. صدّروا نسخة احتياطية بين فترة وفترة.

## مزامنة بين الأجهزة (اختياري لاحقاً)

ما مربوطة أي خدمة خارجية، وما بالكود أي مفاتيح. إذا تريدون مزامنة حقيقية (مثلاً Supabase):
جدول `memories` (id, title, date, desc, tag, by, image_path, created_at) + Storage bucket خاص، وسياسات RLS تسمح بس لحسابكم. المفتاح العام (anon) بس ينحط بالواجهة؛ المفتاح السري ما ينحط بالكود أبداً.

## الاختبارات

```bash
npx http-server -p 8765 . &
node tests/acceptance.mjs
```

يفتح الموقع على 390×844 و430×932 و1440×900، ويجرّب: إضافة/تعديل/حذف ذكرى وبقاؤها بعد إعادة التحميل، حفظ تقدّم الألعاب، قفل النهاية، وكل محطة بالعرض السينمائي التلقائي — ويسجّل أخطاء الكونسول والصور المكسورة.

- لقطات المحادثات نفسها ما انرفعت؛ بس نص الرسائل.
